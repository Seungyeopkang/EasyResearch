# 로컬 PDF 수동 대조 기록

확인일: 2026-10-28. 이 기록은 설치된 공개 기술 문서 한 편을 대상으로 한 부분 점검이며, 학술 논문 표본의 정확도 평가가 아니다. 원본과 이 문서의 렌더링 이미지는 저장소에 복사하지 않았다.

## 대상

- 이 PC에 설치된 Ghostscript 10.08.0의 `doc/GS9_Color_Management.pdf`. 원본 문서는 Ghostscript 9.54의 색 관리 기술 설명서다.
- 원본 SHA-256: `42f7aa0dc0e0fa98d0811a631d8e665ce68ce236cdb80b4fe558a2196ff786a1`, 42개 물리 페이지.
- `pypdf`로 처음 8페이지만 추출하고 Poppler로 물리 1·3페이지를 렌더링해 육안 대조했다. 일부 페이지만 요청했으므로 전체 작업 상태 `partial`은 예상된 결과다.

## 관찰과 변경

- 물리 1페이지의 제목은 해당 추출 페이지에서 발견됐고 물리 2페이지에서는 발견되지 않았다.
- 물리 3페이지의 본문 한 구절이 물리 3페이지에서 유일한 후보로 확인됐고 앞뒤 세 페이지에는 나타나지 않았다. 화면에 보이는 인쇄 페이지 번호는 2였다. 명시적인 PDF 라벨과 물리 페이지 번호는 서로 다른 값으로 유지해야 한다.
- 이 문서에서 `pypdf`는 영어 단어의 `ff`, `fi`를 합자 유니코드 문자로 추출한다. 원문에서 일반 철자로 입력한 발췌가 일치하지 않을 수 있어, 흔한 라틴 합자만 확장해 비교하고 결과 위치는 원래 텍스트의 문자 인덱스로 돌려주도록 변경했다. 수식 위첨자 등은 서로 다른 의미를 유지하도록 일반적인 호환 문자 정규화는 적용하지 않았다.
- 물리 4·6페이지 등의 추출에서는 단어 사이 공백이 빠진 부분이 관찰됐다. 합자 보정으로 해결되지 않으며 문서의 읽기 순서, 표·수식과 그림 내부 텍스트의 정확성을 의미하지 않는다.

합성 한글 스캔 PDF를 사용한 로컬 Windows OCR과 합성 2단·표·수식 페이지 테스트는 별도로 실행했다. 실제 논문에 대한 2단 읽기 순서, 복잡한 표와 수식, 스캔 품질 및 회전·CropBox·정밀 위치 검증은 남아 있다.
