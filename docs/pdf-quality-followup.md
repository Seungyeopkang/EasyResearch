# 공개 논문 PDF 추가 원문 대조

평가일: 2026-10-28. 기존 [평가](pdf-quality-evaluation.md)의 자료와 다른 공개 논문 두 편을 임시 폴더에 받아 대조했다. 사용자 자료를 사용하지 않았고, 원본 PDF와 렌더링 이미지는 저장소에 추가하지 않았다. 이것은 **사례 점검**이며 문서 전체의 정확도나 통계적 성공률을 뜻하지 않는다.

## 자료와 방법

| 자료 | 확인한 버전·조건 | SHA-256 / 크기 / 페이지 | 전체 추출 경과 |
|---|---|---|---|
| Longhi, [Virtual Atom-Photon Bound States and Spontaneous Emission Control](https://arxiv.org/abs/2504.21754v1), v1 | arXiv 공개 원문. [비독점 배포 허락](https://arxiv.org/licenses/nonexclusive-distrib/1.0/)은 arXiv에 대한 허락이므로 제3자 재배포 허용을 가정하지 않음 | `b441def20f2b95b2b2368b797565f743cad363bad23d69a24c74f78d9e8c0d04` / 2,802,093 bytes / 물리 6쪽 | 0.274초 |
| Meuschke 외, [A Benchmark of PDF Information Extraction Tools](https://arxiv.org/abs/2303.09957v1), v1 | arXiv 공개 원문, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) | `cdae51b920dbe4f4c776e586115349af318114a3ede190443a6f0a2495265eae` / 1,007,833 bytes / 물리 23쪽 | 0.353초 |

앱의 `inspect_pdf`와 `locate_quote`, pypdf 5.3.1로 전체 페이지 추출과 표본 문구 검색을 실행했다. Poppler로 Longhi 물리 1·2쪽과 Meuschke 물리 3쪽을 각각 1800픽셀로 렌더링해 눈으로 대조했다. 물리 페이지 번호를 사용하며, 각 문구는 모든 물리 페이지를 검색했다. 시간은 단일 실행의 단순 경과 시간으로 성능 비교가 아니다. 렌더링 시 Poppler가 `Symbol`, `ArialUnicode` 대체 글꼴 부재를 경고했으므로 글리프가 누락될 가능성도 감안했다.

Longhi 2쪽의 그림이 있는 페이지에는 이미지 리소스 경고도 나타난다. 일반 그림과 OCR 레이어를 구분하는 확정 판정이 아니므로 해당 문서를 스캔이라고 해석하면 안 된다. 실제 스캔 연구 논문은 이번 추가 자료에서 확보하지 못했다. 기존 평가의 역사 학술지 소식 자료도 연구 논문이 아니다.

## 후속 조치

1. 줄 끝 하이픈의 모호한 제거를 자동 확정하지 말고, 원문 문자열과 페이지를 보존하면서 대안 검색 후보를 별도로 제시하고 원문 대조를 요구한다. 의미상 하이픈이 필요한 단어도 있어 무조건 제거하면 잘못된 일치가 생긴다.
2. 그림 설명이 본문 중간에 끼거나 표·수식의 구조가 유실될 수 있음을 사용자에게 알린다. 문장 검색 성공을 읽기 순서와 수식 복원의 성공으로 간주하지 않는다.
3. 연구 논문의 실제 스캔, 여러 출판사와 언어, 더 복잡한 표·수식 및 회전·CropBox 사례를 추가하고, 원문 검증 단위·메모리와 처리 시간을 명시한 반복 측정을 수행한다. 별도 파서와의 동일 조건 비교도 필요하다.
